Design Spec Generator

AI-powered design specification and workflow automation tool that creates professional documentation directly in Figma. Built for the cargoes-runner design system.

Overview

Design Spec Generator automates design system workflows using AI agents and the Model Context Protocol (MCP). It handles everything from component documentation to accessibility audits, design system compliance checks, and multi-platform handoffs.

Inspired by Uber's uSpec and the MCP Adoption Toolkit for design teams.

Features

Spec Generation (6 skills)

  • Anatomy: Numbered markers + attribute tables
  • API: Property documentation with types and defaults
  • Properties: Variant grid with live previews
  • Color: Design token annotations per state
  • Structure: Spacing, padding, dimension specs
  • Screen Reader: VoiceOver, TalkBack, ARIA specs

Design Workflows (5 skills)

  • Accessibility Audit: WCAG 2.1 AA compliance checking
  • Design System Audit: Detect hardcoded values and token violations
  • Ticket Validation: Compare designs against acceptance criteria
  • Multi-Tech Handoff: Generate specs for React, Angular, SwiftUI, Compose
  • Token Migration: Audit and batch migrate hardcoded values

Quick Start

Prerequisites

  • Cursor or Claude Code
  • Figma Desktop (not web version)
  • Node.js 18+
  • Figma Personal Access Token

1. Get a Figma Token

  1. Go to Figma API Settings
  2. Create a new Personal Access Token
  3. Enable scopes: File content (Read), Variables (Read), Comments (Read and write)
  4. Copy the token (starts with figd_)

2. Configure MCP

Update .mcp.json in the project root:

{
  "mcpServers": {
    "figma-console": {
      "command": "npx",
      "args": ["-y", "figma-console-mcp@latest"],
      "env": {
        "FIGMA_ACCESS_TOKEN": "figd_YOUR_TOKEN_HERE",
        "ENABLE_MCP_APPS": "true"
      }
    }
  }
}

3. Install Desktop Bridge Plugin

  1. Open Figma Desktop
  2. Go to Plugins → Development → Import plugin from manifest
  3. Navigate to this project and select figma-plugin/manifest.json
  4. Run the Design Spec Generator - Desktop Bridge plugin in your Figma file

Note: The plugin is included in this project at figma-plugin/. You only need to import it once.

4. Run First-Time Setup

In Cursor, open this project and run:

@firstrun

Follow the prompts to configure your template library.

MCP Servers

The project uses two MCP servers:

Server Purpose

figma-mcp-server Code Connect features, design context reading

Workflow Settings

config/spec-generator.config.json contains workflow-specific settings:

{
  "workflows": {
    "accessibility": {
      "defaultStandard": "WCAG21AA",
      "contrastThresholds": { "normalText": 4.5, "largeText": 3.0 }
    },
    "handoff": {
      "platforms": ["react", "angular", "swiftui", "compose"]
    },
    "migration": {
      "batchSize": 50,
      "dryRunFirst": true
    }
  }
}

Best Practices

Session Management

  • Start fresh sessions for each skill
  • Each skill uses significant context
  • Don't chain multiple skills in one session

During Generation

  • Don't interact with Figma while generating
  • Keep Desktop Bridge plugin running
  • Wait for completion before making changes

Providing Context

  • Describe states not visible in the current frame
  • List all variants and their purposes
  • Mention edge cases and error states

Cost Management

  • Scope sessions to specific components/pages
  • Run audits before migrations
  • Use batch operations for efficiency

Troubleshooting

"MCP not connected"

  1. Ensure Figma Desktop is running (not web)
  2. Run the Desktop Bridge plugin in your Figma file
  3. Check the MCP server is configured in .mcp.json

"Template not found"

Run @firstrun to configure your template library.

"Component not found"

Verify the Figma URL contains a valid node-id parameter.

"Skills not showing in Cursor"

  1. Ensure this project folder is open in Cursor
  2. Check .cursor/skills/ contains the skill folders
  3. Restart Cursor

"Token migration failed"

  1. Check if the file is editable
  2. Verify you have edit permissions
  3. Try smaller batches

Security

  • All processing runs locally via Figma Console MCP
  • No design data sent to external APIs
  • WebSocket connection stays on localhost
  • Figma token stored locally in .mcp.json
