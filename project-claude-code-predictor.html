Claude Code Predictor

A VS Code extension that provides AI-powered code suggestions using Anthropic's Claude models.

Features

  • Real-time code predictions and suggestions
  • Support for multiple programming languages
  • Two options for using Claude:
    1. Cloud-based Claude API
    2. Local Claude Code CLI (if installed)
  • Customizable settings for prediction behavior
  • Keyboard shortcuts for triggering predictions

Installation

  1. Install the extension from the VS Code Marketplace
  2. Configure your Claude API key or set up Claude Code CLI

Setting Up

Option 1: Using Claude API

  1. Get an API key from Anthropic
  2. In VS Code, either:
    • Press Ctrl+Shift+P (or Cmd+Shift+P on macOS) and search for "Claude Code Predictor: Set API Key"
    • When prompted automatically on first use
  3. Enter your API key when prompted

Option 2: Using Claude Code CLI (Local)

  1. Press Ctrl+Shift+P (or Cmd+Shift+P on macOS) and search for "Claude Code Predictor: Setup Claude Code CLI"
  2. Follow the instructions in the setup guide
  3. Once installed, the extension will automatically detect and use Claude Code CLI

Using the Extension

  • As you type, the extension will automatically suggest code completions
  • Press Alt+C to manually trigger a code suggestion
  • Code suggestions appear as standard VS Code completions

Configuration Options

  • claudeCodePredictor.apiKey: Your Claude API key (stored securely)
  • claudeCodePredictor.model: The Claude model to use for predictions
  • claudeCodePredictor.contextLines: Number of preceding lines to use for context
  • claudeCodePredictor.useClaudeCodeCLI: Whether to use local Claude Code CLI
  • claudeCodePredictor.claudeCodePath: Custom path to Claude Code binary (if not in PATH)

Security

  • Your API key is stored in VS Code's secure storage
  • When using Claude Code CLI, no API key is required as authentication is handled by the CLI
  • Code context is only sent to Claude's API or processed locally with Claude Code CLI

Troubleshooting

API Key Issues

If you're having trouble with your API key:

  1. Try setting it again with the "Claude Code Predictor: Set API Key" command
  2. Check that the API key is valid in your Anthropic account
  3. Try clearing and re-entering your API key

Claude Code CLI Issues

If Claude Code CLI isn't working:

  1. Verify installation with claude-code --version in your terminal
  2. Check that you've authenticated with claude-code auth login
  3. Restart VS Code after installing Claude Code

Privacy & Data Usage

  • Code context is sent to Claude API for processing
  • No code is stored by the extension beyond the current session
  • When using Claude Code CLI, processing happens through your local account
