# Design system

Abhishek Verma’s portfolio uses warm paper and charcoal, with vermilion as its identifying accent. Light mode uses a deep terracotta accent and warm stone dividers. Dark mode uses a brighter coral accent, warm text and charcoal surfaces. Existing product colors stay inside their presentations.

## Type and layout

Geist carries headlines and body copy. Geist Mono identifies short technical annotations. Oversized headlines use `--display-size` and section headings use `--headline-size`. Body copy stays near 65 characters per line on wide screens. Metric values use tabular numerals.

The shell uses the `--content-width` cap and responsive `--space` gutters. `--section` defines the vertical editorial cadence and `--gap` aligns columns. `--border`, `--rule`, `--radius` and `--elevation` provide separators and restrained depth. The mobile navigation changes at 900px and most editorial split layouts become single-column at 680px. Narrow adjustments begin at 380px. Keep the navigation CSS and JavaScript breakpoint in sync when changing it.

## Identity and interaction

The diagonal orbit is the shared motif for the homepage, favicon and social preview. The three principles use distinct vector diagrams for tracing causes, simplifying interfaces, and sequencing work. Product detail art preserves screenshots and labels illustrative compositions. Brand graphics work without network access.

Interactive surfaces share `--focus`, `--motion` and `--ease`. Use native links, forms, disclosure controls and dialogs. Motion is limited to navigation and useful visual feedback. The reduced-motion rules disable nonessential animations and smooth scrolling. The résumé has a print layout with high-contrast text and jobs grouped where possible.
