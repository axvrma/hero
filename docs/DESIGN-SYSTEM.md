# Portfolio design system

[src/tokens.css](../src/tokens.css) defines the type, colors, button dimensions, project card geometry and responsive breakpoint values. [The reference audit](reference-design-audit.md) describes how each value was measured and the licensed font fallback.

The homepage uses the same section-heading, card and photo primitives across its editorial sections. CSS handles the hero rings, stars, text reveals, work transitions, employer ticker and services illustrations. Native disclosure and dialog elements handle reading, photography and the FAQ. The body is available without JavaScript, with enhanced mobile navigation and motion controls when JavaScript is enabled.
